# Neko Pinball

asobi のムードボードをもとにした、紙とクレヨン調の猫ピンボールゲームです。

「NEKO!」レーンをそろえるとスコア倍率が上がります。各ボールの開始直後には6秒間のボールセーブがあります。

発射は長押し式です。押している間はシューターレーンのゲージに強さがたまり(最大まで約1秒)、はなした強さでボールの飛び出す速さと角度が変わります。弱めだと左奥の `K`、中くらいで `O`、最大まで貯めると右手前の `!` レーンに入りやすく、ねらったレーンを点灯させるスキルショットになります。

`index.html` をブラウザで開くか、静的ファイルサーバーでこのフォルダを配信してください。

## 操作

- 左フリッパー: `A` / `←`
- 右フリッパー: `D` / `→`
- ボール発射: `Space` を長押し → はなすと発射(押している長さ = 強さ)
- 一時停止: `Esc`
- スマートフォン: 画面下の操作ボタン(発射ボタンも長押しで強さを調整)

キーボードの `Enter` で発射ボタンを押した場合は、長押しができないため中間の強さで発射します。
