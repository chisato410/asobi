# Cookie shower

「すべてのクッキーを受け入れますか？」に答えると、手描きのクッキーが降ってくる1画面のWeb体験です。
クッキーと同時に、ぽっちゃりした猫・犬・レッサーパンダが画面下から喜んで飛び出します。
回答後は、受け入れ方に合わせた文章でXの投稿画面を開けます。

`index.html` をブラウザで開くか、このフォルダで静的サーバーを起動して確認できます。

## Files

- `index.html` — 画面の構造
- `styles.css` — ムードボードに合わせた紙・クレヨン調の見た目とアニメーション
- `script.js` — 回答、クッキーシャワー、リプレイの処理
- `assets/cookie.png` — 透過背景の手描きクッキー素材
- `assets/animal-cheer.png` — 喜ぶ猫・犬・レッサーパンダの透過素材
- `og-image.png` — 1200 × 630 pxのSNS共有用画像
