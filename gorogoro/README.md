# ごろごろ限界

猫を長押しでなでて、ごろごろゲージをためる30秒のなでなでチキンレースです。ぷいっと怒られる前に離すのが目標で、ギリギリまで粘るほど高得点になります。10/16のグローバルキャットデーに合わせて作りました。

## あそびかた

- 猫を長押し(キーボードはスペースキー)でなでると、ごろごろゲージがたまります。離したときのゲージが点数のもとです。
- ぷいっの少し前に、猫が震えて「!」が出ます。「!」の間は、離すのが遅いほどボーナスが大きくなり、画面に「いま離すと +○○」と出ます。「!」が消える前に離さないと、ぷいっで0点です。
- ぷいっの直前(パーフェクト)で離すと、コンボが2つ進みます。コンボが続くほど点数の倍率が上がり、最大×1.5になります。ぷいっされるとコンボは途切れ、1.5秒のロスになります。
- 残り8秒はラストスパートで、点数が×1.5になります。ときどき来る「ひかる猫」は点数×2.5ですが、ぷいっも早くなります。
- 離したあとに「あと0.12秒でぷいっ!だった」と、ぷいっまでの余裕が出ます。
- 猫は5匹で、ごろごろの進み方、「!」の長さ、点数の倍率がそれぞれ違います(`script.js` の `CATS`)。しろふわはどんどん加速し、のびねこは最初ゆっくりです。みけねこは、「!」なしでぴくっとするだけのこともあります。

## 起動

静的サイトなので `index.html` を直接開くか、このディレクトリでHTTPサーバーを起動します。

```sh
python3 -m http.server 4173
```

## 素材と音

猫のイラストは `nekoris/assets/cat-pose-*.png` から余白を切り詰めて縮小したものです。効果音とごろごろ音はWeb Audio APIで生成していて、音声ファイルはありません。

## 共有とOGP

結果画面から、スコア入り画像またはリンクだけをXへ共有できます。公開URLとOGPは `https://asobi-gorogoro.vercel.app/` を参照します(Vercelのプロジェクト名を `asobi-gorogoro` にする前提です)。OGP画像は1200×630pxの `og-image.png`、共有画像のベースは文字なしの `og-art.png` です。
