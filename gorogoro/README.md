# ごろごろ限界

猫を長押しでなでて、ごろごろゲージをためる30秒のなでなでチキンレースです。猫が「ぴくぴく」したら「ぷいっ」の合図。その前に手を離すと得点になり、離すのが遅いと0点です。10/16のグローバルキャットデーに合わせて作りました。

## あそびかた

- 猫を長押し(キーボードはスペースキー)でなでると、ごろごろゲージがたまります。
- 離したときのゲージが点数です。ゲージ40以上で「ごきげん」としてカウントされます。
- ぴくぴく(!マークとゲージの色)が出たあとに離すと「ギリギリ」ボーナス、ゲージがMAXまでたまると「MAX」ボーナスです。
- 猫は5匹で、ごろごろの速さ、ぷいっとなるまでの長さ、合図の短さ、点数の倍率がそれぞれ違います(`script.js` の `CATS`)。みけねこだけは、ぴくっとしても実際には怒らないフェイントがあります。

## 起動

静的サイトなので `index.html` を直接開くか、このディレクトリでHTTPサーバーを起動します。

```sh
python3 -m http.server 4173
```

## 素材と音

猫のイラストは `nekoris/assets/cat-pose-*.png` から余白を切り詰めて縮小したものです。効果音とごろごろ音はWeb Audio APIで生成していて、音声ファイルはありません。

## 共有とOGP

結果画面から、スコア入り画像またはリンクだけをXへ共有できます。公開URLとOGPは `https://asobi-gorogoro.vercel.app/` を参照します(Vercelのプロジェクト名を `asobi-gorogoro` にする前提です)。OGP画像は1200×630pxの `og-image.png`、共有画像のベースは文字なしの `og-art.png` です。
